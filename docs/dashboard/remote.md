# Remote

The **Remote** tab, `/?tab=remote`, is the Control tab's remote on a single screen: it fits the height of a phone, so nothing has to be scrolled to reach a button while watching.

## The screen

* **Keys along the top:** Panel, Source, Apps, Sound, Picture and Open a web page. Each opens a sheet from the foot of the screen with that control in it, and closes again on the key, the cross, the background or Esc. Panel holds screen off, screen on, the screensaver, and power and reboot where they are offered.
* **Touchpad or D-pad:** one at a time, in the space between the keys, chosen by the pair of buttons above it. The choice is kept per browser.
* **Keyboard:** beside the pad buttons. It opens by itself when a text field on the TV is selected, such as the web browser's address bar, and what is typed there replaces the field's text and presses Enter. Apps that draw their own keyboard, YouTube among them, cannot be typed into this way.
* **Along the foot:** volume up, mute and volume down, then Back, Home and Settings, and the playback keys.

Volume and the D-pad's arrows repeat while held, as the remote's own keys do.

Each control here is the Control tab's own, moved to this tab while it is open, so there is one of each and both tabs always agree. The [Control](control.md) tab keeps everything, including the sleep timer and the screen notification, which the Remote tab leaves out.
